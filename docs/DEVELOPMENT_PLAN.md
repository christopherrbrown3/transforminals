# Development plan

Work in playable vertical slices. A phase is complete only when its acceptance points are implemented and validated; a listed or planned feature is not evidence of completion.

| Phase | Milestone             | Exit evidence                                                                                                                                                                                                                                                                                                                                                |
| ----- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0     | Foundation            | **Verified.** Static shell builds, checks pass, the public foundation shell was served through Pages, and production-preview offline shell/model behavior passes in Chromium.                                                                                                                                                                                |
| 1     | Meadow slice          | **Automated acceptance passed.** Human movement, visible jump control, forgiving rescue, transformation, save/reload, and touch-profile browser coverage pass.                                                                                                                                                                                               |
| 2     | World exploration     | **Core implemented; broad rescue flow passes.** Ten biomes load; all 22 required cage jumps, city-cow gate access, wildlife dialogue, and portal routes pass browser automation. Map discovery/return and forward-gate checks also pass.                                                                                                                     |
| 3     | Advanced environments | **Core implemented and browser verified.** Ocean, Volcano, Underground, and Rifts load; Ocean creatures rescue; connected cave rooms and the optional crystal nook are now authored. Ocean/Beach swim bounds, release behavior, lava recovery, cave traversal, saved discovery, and landing recovery pass in both browser engines.                           |
| 4     | Bosses                | **All six encounter flows verified in browsers.** Shared hit/heart logic, mini-boss defeat, skip, and replay safety pass; the other four mini-boss variants also pass the shared stomp/skip flow.                                                                                                                                                            |
| 5     | City and finale       | **Automated acceptance passed for core loop.** All city cages, final gate, five stomps, heart feedback, saved victory, and continued exploration pass in Chromium and WebKit.                                                                                                                                                                                |
| 6     | Polish                | **In progress.** Source now includes original biome soundscapes, settings and update diagnostics; settings, siren/boat gag, update-cutscene deferral, pointer-cancel/blur/orientation, route and bounded resource checks pass. Physical iPad feel/install, sustained performance, accessibility, remain open; original asset/source licensing is documented. |

Detailed requirements and current status live in [REQUIREMENTS.md](REQUIREMENTS.md). GitHub milestones mirror these phases. Do not start broad content expansion before the playable Meadow slice works.
