# Development plan

Work in playable vertical slices. A phase is complete only when its acceptance points are implemented and validated; a listed or planned feature is not evidence of completion.

| Phase | Milestone | Exit evidence |
|---|---|---|
| 0 | Foundation | Static shell builds, CI checks it, Pages publishes it, and manifest/service worker are verified. |
| 1 | Meadow slice | Playable human movement, forgiving cage-top rescue, animal form, local save, feedback, and real iPad-oriented browser coverage. |
| 2 | World exploration | Connected biome framework, Winter, Savannah, Desert, Beach, navigation, rescues, and wildlife. |
| 3 | Advanced environments | Ocean/Atlantis and easy underwater movement, boy siren, Lava, Underground, Nether-inspired dimension, and portals. |
| 4 | Bosses | Reusable boss flow, an initial mini-boss, friendly readable encounters, and the toilet monster defeat. |
| 5 | City and finale | City and required city rescues, gated final arena, five-stomp/three-heart finale, persistence, and continued play. |
| 6 | Polish | Touch/camera, visual cohesion, audio, performance, PWA install/update, save migration, accessibility, and regression fixes. |

Detailed requirements and current status live in [REQUIREMENTS.md](REQUIREMENTS.md). GitHub milestones mirror these phases. Do not start broad content expansion before the playable Meadow slice works.
